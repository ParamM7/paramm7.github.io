PINN Airfoil Self-Noise

Uniform and cascading physics-informed neural networks for trailing-edge noise prediction on the NASA NACA 0012 dataset — architecture search, epoch sensitivity, and comparison against Gradient Boosting benchmarks.

Context

Airfoil self-noise — specifically turbulent boundary-layer trailing-edge (TBL–TE) noise — is the dominant acoustic emission for wind turbines, aircraft fans, and propeller-driven UAVs at low Mach numbers. Classical semi-empirical models (Brooks–Pope–Marcolini) are fast but narrow in applicability; high-fidelity aeroacoustics is accurate but expensive. This project explores physics-informed neural networks as a middle ground, embedding a physical smoothness constraint derived from Ffowcs Williams–Hall theory directly into the loss function.

The work was conducted as a term project for the Minor in Data Science (Nirma University), co-authored with Dharmik Jha and Vanshi Raiththa.

Dataset and Feature Engineering

The NASA NACA 0012 self-noise dataset contains 1,503 wind tunnel measurements from NASA Langley Research Center. Each sample records a unique combination of frequency, angle of attack, chord length, free-stream velocity, and suction-side displacement thickness. The prediction target is the Scaled Sound Pressure Level (SSPL), ranging from 103.4 to 141.0 dB.

Three engineered features were derived from the physical literature to bring the input dimension to nin = 8:

  • Chord Reynolds number Re = U∞c/ν — captures the combined velocity–chord effect at constant kinematic viscosity (ν = 1.5 × 10−5 m²/s).
  • Strouhal number St = fc/U∞ — the natural non-dimensional frequency in trailing-edge noise scaling from the BPM model.
  • Log-frequency ln(f) — linearises the two-decade frequency range, motivated by LES validation work by Aihara et al. (2021).

The dataset was split 80/20 (1,202 train / 301 test, random_state=42). Both inputs and the SSPL target were independently z-score normalised using training-set statistics only; all metrics are reported after inverse-transform to the original dB scale.

Physics Loss

No explicit governing PDE exists for the empirical SSPL relationship, so the physics penalty encodes a known physical property of the solution: the aeroacoustic response surface is smooth and continuous in all input parameters. Large gradients in the predicted surface are physically implausible. The physics loss is:

Ltotal = Ldata + λ · Lphysics  =  (1/N)Σ(ŷ−y)² + λ · ⟨‖∂SSPL/∂x‖²⟩

The gradient penalty is evaluated via TensorFlow's nested GradientTape automatic differentiation. λ = 0.1 and Adam at η = 10−3 were held constant across all experiments. Target normalisation proved critical: without it, the data loss operates at O(100) dB² while the physics loss operates at O(0.01–0.1), creating a severe scale mismatch that effectively disables the physics term.

Architecture Variants

Uniform-width PINN: D hidden layers of W neurons each (ReLU), one linear output. Parameter count: Nparams = ninW + DW² + W + 1.

Cascading-width PINN: Layer width halves geometrically at each depth: Wi = ⌊W₀/2i⌋ for i = 0,…,D−1. For D=4, W₀=256, this produces the sequence:

Input (8) → 256 → 128 → 64 → 32 → Output (1)
87,041 parameters · ReLU activations · linear output · Adam η=10⁻³

Early wide layers extract rich feature representations; narrower final layers act as a learned dimensionality reduction before the output regression. This concentrates representational capacity where it matters most (Montufar et al., 2014).

Experiment 1 — Uniform Grid (1500 epochs)

18 configurations crossing D ∈ {2,3,4,5,6,8} and W ∈ {64,128,256}. All achieve R² > 0.95 — a substantial improvement over earlier 300-epoch evaluations (best R²=0.939), explained jointly by 5× more training and target normalisation. Width 256 consistently outperforms narrower configurations at equal depth; optimal depth at W=256 is D=5, with D=6 and D=8 nearly identical (R²=0.9743), indicating saturation beyond depth 5.

Experiment 2 — Cascading Grid (1500 epochs)

Same depth × starting-width grid with the cascading architecture. The best result (D=4, W₀=256: R²=0.9784) surpasses the best uniform result (R²=0.9749) by ΔR²=0.0035 while using ~87K parameters versus ~295K — 3.4× more parameter-efficient. Two systematic failure patterns emerged:

  • Degenerate bottleneck: D=8 with W₀ ∈ {64,128} fails completely (R²≈0) because geometric halving reduces the final layer width to 1, preventing gradient flow.
  • Cascade depth saturation: Performance degrades at D≥5 for all W₀ values; cascading removes capacity faster than additional depth recovers it.

Experiment 3 — Epoch Sensitivity

The best uniform configuration (D=5, W=256) was re-trained from scratch at five epoch budgets: 500, 1000, 1500, 2000, and 5000. Performance improves monotonically across the full range. The steepest gain occurs between 500 and 1500 epochs; improvement rate slows but does not saturate at 5000 epochs.

Comparative Analysis

The 5000-epoch uniform PINN (R²=0.981) exceeds the Gradient Boosting benchmark from Pandey et al. (R²=0.966, RMSE=1.262 dB). The 1500-epoch uniform result (R²=0.975) also exceeds this benchmark independently of epoch count. Physical regularisation likely prevents the over-parameterised network from fitting noise in the 1,202-sample training set — the regime where neural networks historically underperform ensemble methods on tabular data.

Outcomes and Future Work

  • Cascading architectures achieve equal or better accuracy than uniform networks at 3.4× lower parameter count — practically valuable in latency-constrained deployment (real-time blade design optimisation).
  • Target normalisation is the critical training stability factor, not epoch count — it resolves the loss scale mismatch between the physics and data terms.
  • Extending the physics loss from generic gradient smoothness to explicit BPM aeroacoustic residuals (U∞5 velocity scaling, Strouhal-number frequency law) would add harder physical constraints.
  • A cosine learning rate schedule would improve convergence efficiency beyond 2000 epochs; current results show diminishing returns at constant η = 10−3.
  • Dropout regularisation on the best cascade configuration and residual (skip-connected) architectures for very deep configurations remain as open experiments.
